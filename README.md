# One thing at a time

Eine minimalistische, ästhetische und druckfreie Fokus-Webanwendung, die Menschen dabei unterstützt, sich bewusst auf genau eine Sache zu fokussieren und Überforderung sowie Schuldgefühle abzubauen.

Live auf GitHub Pages: [https://alissa-prohl.github.io/one-thing-at-a-time/](https://alissa-prohl.github.io/one-thing-at-a-time/)

---

## Funktionen

- **Startseite**: Großes Eulen-Maskottchen mit runder Brille, das bei noch offenem Fokus in entspanntem Schwarz-Weiß ruht und nach dem Klick auf *„Heute gemacht!“* in voller Farbe erstrahlt.
- **Gedanken-Parkplatz**: Ideen und Vorhaben schnell notieren, um den Kopf frei zu bekommen. Ein Klick öffnet das Detail-Fenster („Was genau?“ und „Warum?“), um die Idee als Wochenfokus festzulegen. Alle anderen Gedanken werden dezent ausgegraut.
- **Wochen-Tracker**:
  - Flexibles 7-Tage-Startdatum (frei wählbar, ohne an Montage oder Sonntage gebunden zu sein) mit integriertem Mini-Kalender.
  - Smartphone-optimierte Ansicht (4x2-Raster oder komfortable Listenansicht).
  - Druckfreie Dokumentation mit Eulen-Icons (feine Kontur für offene Tage, farbige Eule für gemachte Tage).
  - Keine roten Fehlersymbole, keine abgebrochenen Streaks.
- **Dauerhafte Speicherung**: Alle Daten und Zustände werden lokal im Browser (`localStorage`) gespeichert.
